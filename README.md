# github-core-clone-01

An in-memory, GitHub-compatible git forge: git smart HTTP (upload-pack v2 and receive-pack), REST v3, GraphQL v4 and MCP, all served from a single Node 22 process with a deterministic clock so trials and replays answer byte-identical bytes.

## Run it

```sh
node --experimental-strip-types main.ts
```
